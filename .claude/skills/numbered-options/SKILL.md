# Numbered Options

When asking the user to choose, decide, or approve an action in text, number every actionable option.

- Use a stable integer prefix: `1.`, `2.`, and so on.
- When there is only one action to approve, still write it as `1. <action>`.
- Keep one-action workflows as one action. Numbering does not justify adding a skip path, alternatives, or an option menu.
- Number choices, not the supporting evidence that explains the recommendation.
- Make the recommendation explicit when appropriate, then present its numbered action.

This enables a concise numeric reply such as `1` followed by Return.
