While a message's style menu is open, gap handles, the divider menu, occurrence create-drag, collapse buttons and participant insertion no longer react, and only the selected message shows a reorder handle; a press on them only closes the menu. A selected message whose menu is closed blocks nothing. While a gap's insert menu is open, other gap handles and on-canvas controls no longer react, and only one gap menu can be open at a time.
