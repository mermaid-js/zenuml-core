While a message is being reordered by drag, the other messages no longer reveal their reorder handles on hover, and while a message is being created by drag, occurrences no longer show the "Drag to create a message" hint. The occurrence collapse button no longer appears on hover while another interaction (the participant editor, a menu or a drag) owns the diagram. Participant insert buttons now stay available while a participant is only highlighted (participant style editing off). In static rendering, clicking a participant no longer highlights it.
